# Model inversion

- An attempt at extracting training data from the model.
- This can be done by extracting specific data, inferring sensitive attributes, or reconstructing inputs based on the model's responses.
- This can occur on models trained using large-scale training data which is not cleaned or filtered prior to moving to production.
- Example:
  - Repeated queries with small variations in each query. This tries to identify consistent patterns in the model response.
  - Models trained on specific individuals' personal attributes (age, sex, political affiliation) can be identified through careful prompting.

## Mitigation

- Apply differential privacy during training.
- Limit exposed confidence scores and detailed outputs.
- Rate-limit and monitor repeated, near-identical queries.
