# Sensitive information disclosure

- An AI model reveals private information in response to a query.
- This is often triggered through a carefully crafted query.
- Disclosed data may include PII, credentials, proprietary data, or the system prompt.
- Training data should be properly scrubbed of sensitive information.
- Prevention includes:
  - Strict data curation during model training.
  - Rigorous prompt filtering.
  - Review of model responses to edge cases.
  - Output filtering to redact sensitive data before it reaches the user.
