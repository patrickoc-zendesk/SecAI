# Model theft

- Organisations that train their own models are a target of model theft.
- Model theft occurs when an attacker steals or replicates a private model.
- An attacker may obtain the files directly or interact with the model in a way that lets them reproduce it.
- The motivations behind model theft could be:
  - Avoid the cost of model development
  - Reverse engineer the model
  - Prepare for other attacks such as model inversion or adversarial input manipulation
- There are two main ways model theft can occur:
  - Direct access to the model files. If the architecture and training weights are stolen, the model can be retrained elsewhere.
  - Remote query theft recreates the model by interacting with it. This approach works best when the model returns confidence scores or probability distributions, as these leak information about the model.
- The consequences can include loss of investment, violation of privacy obligations, and legal risk.
- If the model is used for security or malware identification, attackers can use model information to learn how best to avoid detection for their next attack.

## Mitigation

- Rate-limit and monitor queries for extraction patterns.
- Restrict confidence scores and probability distributions in responses.
- Apply access controls and encryption to model files and weights.
