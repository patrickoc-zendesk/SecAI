# Backdoor and trojan attacks

- A backdoor causes a model to respond in an attacker-controlled way when a specific trigger is present
- Trojan attacks embed hidden malicious behaviour in AI artefacts
- Attack vectors for these attacks include:
  - Poisoned training data
  - Poisoned model weights
  - Compromised supply chain
- Defending against these means preventing the initial compromise:
  - Use trusted sources
  - Verify downloads
  - Treat model updates and third-party components as untrusted code
- Test:
  - Use tests that reveal hidden behaviour by looking for inputs that cause sudden out-of-character responses, rather than relying only on broad accuracy checks
- Limit impact by:
  - Adding extra checks before the model performs high-impact actions
