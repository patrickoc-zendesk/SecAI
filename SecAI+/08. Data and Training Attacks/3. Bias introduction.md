# Bias introduction

- The introduction of unfair, unbalanced, or harmful outputs produced by a model
- Can be part of an intentional attack or unintended as part of the model development process
- Intentional: an attacker skews training data or labels to push the model toward biased outcomes
- Unintentional: unrepresentative datasets, poor sampling, or biased labelling introduce bias by accident
- Security relevance: biased models can be manipulated, produce discriminatory decisions, and erode trust
- Mitigations: use representative and balanced datasets, audit for bias, and apply fairness testing before deployment
