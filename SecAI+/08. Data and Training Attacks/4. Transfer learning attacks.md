# Transfer learning attacks

- Transfer learning fine-tunes a pre-trained model for a new task
- A useful development shortcut, valuable when data or compute resources are limited
- Fine-tuned models inherit any hidden issues in the original model
- If an attacker compromises the foundation model, fine-tuning still carries the compromise forward
- Attackers may distribute malicious models through public sources
- Transfer learning can amplify issues such as bias in the underlying model
- Mitigations: treat external models as untrusted code, verify provenance, and evaluate fine-tuned models for hidden or backdoored behaviour
