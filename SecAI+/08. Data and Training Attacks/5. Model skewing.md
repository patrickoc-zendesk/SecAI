# Model skewing

- An intentional attempt to distort an AI system's behaviour over time by manipulating the data it consumes or the way people use it
- The model's architecture or code is not targeted; instead the attacker nudges the outputs in a specific direction
- Most effective against reinforcement learning pipelines or feedback loops (systems that update themselves)
- The attacker follows the normal processes users are expected to take, making it difficult to detect
- Example: repeatedly submitting crafted feedback so a recommendation or spam filter drifts toward the attacker's goal
- Mitigations:
  - Validate user input
  - Monitor feedback loops
  - Detect and correct skew through periodic model review
