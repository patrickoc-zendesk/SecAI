# Unsupervised learning

- Models explore unlabelled datasets with no predefined answers.
- Models identify patterns and outliers.
- Can be used to identify unexpected patterns such as suspicious network traffic.
- Clustering groups similar data together and is an example of an unsupervised learning technique.
- Dimensionality reduction simplifies complex data by removing redundancies and low value features for easier data interpretation.
- Principal Component Analysis (PCA) is used for dimensionality reduction and is frequently used in cybersecurity.
- PCA helps reveal patterns and anomalies within large volumes of data such as network traffic.
- Unsupervised learning results can be difficult to interpret due to a lack of human type reasoning.
