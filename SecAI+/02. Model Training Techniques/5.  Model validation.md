# Model validation

- The process of testing a model on new data.
- Ensures the model learns generalisable patterns rather than over-learning or overfitting the model.
- Overfitting occurs when the model is too closely tailored to the training data and fails to generalise to unseen data.
- Concept drift occurs when the patterns in the data change over time, meaning that a model may no longer identify patterns due to changes in user behaviour, system configuration, attacker techniques etc.
- A model trained on older data may miss or incorrectly identify more recent data.
