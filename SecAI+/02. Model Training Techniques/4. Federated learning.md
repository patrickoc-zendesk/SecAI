# Federated learning

- A collaborative training approach designed to protect data privacy.
- FL allows models to be trained directly where the data resides.
- Workflow:
  - A central server sends an initial global model to many devices or orgs.
  - Each participant trains a local copy of the global model using their own data.
  - Each local model then sends model updates, but not the raw data, back to the central server.
  - The server aggregates these updates to improve the global model.
  - The updated global model is then sent to the local devices and the cycle continues until convergence.
  - Convergence is when the model stabilises and training stops.
- FL reduces privacy risks and enables regulatory compliance as sensitive data is never sent to the central server.
