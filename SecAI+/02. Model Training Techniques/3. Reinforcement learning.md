# Reinforcement learning

- RL teaches an agent to make adaptive decisions by interacting with an environment.
- The agent takes an action, receives feedback (a reward or penalty) and adjusts behaviour to maximise positive feedback.
- Learns over time and continually improves based on previous results.
- RL requires many iterations to learn effectively; training often happens in simulated environments.
- Can be used to automate complex decision making processes.
- RLHF (reinforcement learning with human feedback) uses human ratings to shape the reward signal, commonly used to align LLM behaviour.
