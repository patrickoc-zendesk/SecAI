# Prompt firewalls

- Inspects, filters, and sanitises user requests before they reach the model.
- Sits between the user/application and the model, acting like a WAF for LLM traffic.
- Protects against prompt injection.
- Can help prevent sensitive data leaks and policy violations.
- Some can review model output before it reaches the end user, such as content that violates company policies.
  - Also referred to as an AI/LLM guardrail; can inspect both inbound prompts and outbound responses (bidirectional filtering).
- The most effective prompt firewalls combine static rules with intelligent detection (i.e., machine learning models that recognise more subtle or contextual risks).
- No firewall can stop all attacks, however it significantly reduces the risk of sensitive data exposure and model jailbreaking.
