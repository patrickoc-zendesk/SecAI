# Network and API access controls

- Controlling network/API access ensures only legitimate requests reach a model.
- Controls include:
  - Enforcing authentication, authorisation and usage limits.
  - Apply network isolation
    - AI models should not be directly exposed to the public internet.
    - Access should be provided in private networks or cloud subnets only accessible through secure gateways.
    - IP allowlisting, Virtual Private Clouds and gateways can restrict which systems or users can connect.
  - Use secure communication protocols
    - Encrypt data in transit through HTTPS and TLS.
  - Implement throttling and circuit breakers
    - Network controls which help maintain stability.
    - Throttling limits how many requests can be processed.
    - Circuit breakers automatically pause or reroute traffic if the system becomes overloaded.
- Audit logging paired with network and API access controls enhances visibility and accountability.
