# Model access controls

- Determines who has access to a model, what they can do to it and how they access it.
- This can prevent unauthorised use and theft.
- Authentication is the first line of defence.
  - All users should have valid credentials for their account and level of access.
  - For AI systems, this means authentication services need to be integrated into model access control (e.g., SSO, AD).
- External access can be provisioned through an API token or other similar approach.
- RBAC or ABAC is also essential in access control.
  - RBAC determines level of permissions based on the authenticated user's role.
  - ABAC applies additional levels of permissions depending on varying factors such as device type, time of day, user location.
- API gateways and access management systems can also be used.
- Protecting the model's weights, configurations and supporting files is critical; they should be encrypted at rest and have strict access control applied.
- Monitoring for suspicious access or data exfiltration attempts is also critical, as well as monitoring for general anomalous activity.
  - Set usage quotas or rate limits.
