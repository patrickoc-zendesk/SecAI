# Agent access controls

- An agent can be manipulated into performing unwanted actions.
- To control the level of agent access, the following controls can be applied:
  - Rate limiting & monitoring
    - How often an agent can act within a specific timeframe.
    - A combination of these controls provides adaptive defence against agent compromise.
  - Apply the principle of least privilege
    - Treat agents like users, i.e., they should only have access to the least amount of permissions required to complete their task.
    - Direct connections between agents and critical systems should be avoided.
  - Review and approval mechanisms
    - Require an engineer to approve code changes or other potentially risky actions.
