# Penetration testing

- AI can be used to automate some pentesting tools and techniques
- Assists with reconnaissance, scanning, and identifying likely attack paths
- Can help generate and adapt exploit payloads and craft social engineering pretexts
- Speeds up reporting by summarising findings and suggesting remediation
- Human oversight remains essential; AI augments but does not replace a skilled tester
