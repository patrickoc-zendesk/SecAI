# Secure code development

- Code linting scans source code for issues (code smell)
  - AI-assisted linting enhances this by learning the expected syntax for the team and identifying risky patterns
- AI vulnerability analysis creates actionable plans
  - AI tooling can help inform prioritisation and highlight false positives
- Can create recommendations that go directly to developers
- AI can assist in performing threat modelling by highlighting attack patterns and introducing threat intelligence
- Static (`SAST`) and software composition analysis can be augmented by AI to reduce noise and suggest fixes
- Caution: AI-generated code and suggestions must still be reviewed, as models can introduce insecure patterns
