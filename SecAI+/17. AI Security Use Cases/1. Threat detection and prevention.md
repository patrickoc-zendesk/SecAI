# Threat detection and prevention

- Signature detection
  - Matches known malicious behaviour
  - Includes hashes, code snippets and traffic patterns
  - Only effective if you have a signature
  - Requires keeping signatures current
- AI can be used to detect signatures
- AI can also be used to create signatures
- Anomaly detection identifies deviation from normal activity
  - Learns what normal looks like, then flags activity that falls outside of this
  - Can surface novel or zero-day threats with no known signature
- Security information comes in many forms; AI can help recognise security-relevant information and trends in large datasets
- Fraud detection can also be improved through the use of AI tooling
  - Reviews historical patterns and adapts to new techniques
- Trade-off: anomaly-based approaches can raise false positives; tuning and human review remain important
