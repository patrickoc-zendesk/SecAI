# Data encryption

- Encryption can help protect data in 3 states:
  - At rest
    - Stored data such as training datasets, model artefacts, feature stores and system logs.
  - In transit
    - Data moving over networks between systems and their components (e.g., API calls between services).
    - Prevents interception.
    - TLS and HTTPS must be used to protect confidentiality and integrity of the information.
  - In use
    - Data that is actively being used for computation.
    - Data typically must be unencrypted in memory for computation.
    - Confidential computing using a hardware-based Trusted Execution Environment (TEE) creates safe memory regions for secure processing.
    - Homomorphic encryption is also used to encrypt data in use, as it enables computations to be performed directly on encrypted data. The results are also encrypted. Very resource intensive.
