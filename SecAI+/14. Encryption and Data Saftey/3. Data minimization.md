# Data minimisation

- The principle of collecting, using and keeping the minimum amount of data needed for a specific purpose.
- Effective at reducing security risks and maintaining compliance with privacy laws (e.g., a core GDPR principle).
- It is also important for training data.
  - Decide what is truly necessary to train the model.
    - Remove unnecessary identifiers to reduce risk.
  - Limit prompt content.
    - Only necessary information from the prompt should be used.
  - Minimise prompt outputs.
    - Responses should only contain necessary information.
    - Focus strengthens user experience and privacy.
  - Shorten data retention.
    - Retain conversation logs only as long as needed, then delete them.
  - Minimise feature size.
    - Use only the features required for the model to perform its task.
