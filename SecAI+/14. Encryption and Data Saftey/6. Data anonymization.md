# Data anonymisation

- Removing or modifying identifiers in a dataset.
- Data cannot be traced back to an individual.
- Should happen as early as possible in the data pipeline.
- Leaves no link by removing direct and indirect identifiers.
- Pseudonymisation replaces identifiers with fictitious values.
  - The key linking the data is stored securely.
  - Usually reversible, unlike data masking which is irreversible.
  - Used when maintaining relationships between records is essential, unlike data masking where realism matters more than traceability.
- Synthetic data enables analysis with realistic-looking data without risking privacy.
