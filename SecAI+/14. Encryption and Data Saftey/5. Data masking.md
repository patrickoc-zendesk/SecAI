# Data masking

- A technique used to protect sensitive information by replacing it with a fictitious value.
- This preserves the structure and usefulness of data without exposing private details.
- In AI systems, data masking is a common technique used when preparing training data.
- Can be applied in 2 ways:
  - Static
    - Permanently masks a copy of a dataset.
  - Dynamic
    - Replaces values in real time as data is accessed, based on permissions.
    - Useful when multiple systems share a central database (prod uses unmasked data while staging gets masked versions of the same record).
- Data masking should be combined with other approaches to enhance effectiveness.
  - Use generalisation (e.g., only show birth year when input is a DOB).
