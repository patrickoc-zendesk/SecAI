# Input manipulation

- Attackers craft data that causes the model to misbehave.
- Exploitation does not target the model directly, but rather how the model interprets what it receives.
- Often uses adversarial examples: inputs with small, deliberate perturbations that are imperceptible to humans but change the model's output.
- Example:
  - Facial recognition might misidentify someone wearing specially crafted glasses.
  - Use of sarcasm, e.g. "Brilliant move putting geniuses like this in charge of security", to evade a sentiment or content filter.

## Mitigation

- Adversarial training on perturbed samples.
- Input validation and sanitisation.
- Robustness testing before deployment.
