# Data verification

- Once data is cleaned it needs to be verified that it is genuine, intact and traceable to a trusted source.
- Data verification involves comparing data against trusted references or known standards
- This may include cross-referencing internal records, internal databases, or authoritative sources
- Cryptographic tools can be used for verification
  - Checksums and hashes (e.g. `SHA-256`) help detect modifications during transfer or while in storage
- Data verification ensures that models are only trained on trusted data that has not been tampered with
- Distinct from validation: verification confirms data is authentic and unaltered; validation confirms it meets format/business rules.
