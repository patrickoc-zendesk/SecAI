# Data augmentation

- Data augmentation is used to enhance the size and variety of data
- This can be used to overcome the challenge in AI development of not having enough diverse or balanced training data
- This happens by creating new examples from existing ones
  - Example: for images, applying rotation, flipping, cropping, scaling or noise to existing samples
- Benefits include:
  - Enhancing model performance
  - Improving resilience to adversarial actions
  - Reducing the cost of data acquisition
- Also helps reduce overfitting by exposing the model to greater variation.
