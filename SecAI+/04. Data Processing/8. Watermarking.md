# Watermarking

- Watermarking embeds a hidden signature or pattern in data.
- This helps verify ownership, detect tampering, and prove authenticity long after the content has left its original source.
- Watermarking serves three main purposes:
  - Supports provenance
    - Watermark can be used to identify what model created the content
  - Supports intellectual property protection
  - Helps preserve integrity
- Used to label AI-generated content, helping counter deepfakes and misinformation.
