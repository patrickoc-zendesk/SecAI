# Data types

- There are 3 types of data AI systems depend on:
  - Structured:
    - Neatly organised in a fixed, predefined format with clearly defined fields
    - RDBs, Tables, Sheets
    - A high value target for attackers
    - Protection requires strong access control management, encryption in transit and rest, regular audits, and integrity checks to identify unauthorised changes.
  - Unstructured:
    - Lacks predefined structure or organisation
    - More flexible but more difficult to manage
    - Includes text documents, social media posts, audio files, images, and videos
    - Difficult to categorise and so tricky to secure due to lack of predefined format.
    - Can easily contain sensitive information.
    - Protection includes file-level encryption, redaction tools and metadata sanitisation to remove hidden identifiers or location tags that could expose users.
  - Semi-structured:
    - Data combines both structured and unstructured data
    - JSON, XML, email headers
    - Contains partial organisation through tags or key-value pairs but do not follow rigid schemas.
    - Securing this type of data means encrypting both data and metadata, monitoring API activity, validating inputs and outputs to block harmful data before it enters the system.
