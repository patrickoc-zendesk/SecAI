# Data cleansing

- Data cleansing is the process of identifying errors, inconsistencies and irrelevant data before it reaches a training pipeline in order to make the data accurate and consistent.
- Examples include:
  - Fixing typos/typographical errors
  - Filling in missing values
  - Standardising formats
  - Eliminating duplicate or incomplete records
- In the context of cybersecurity, this includes:
  - Removing log entries with invalid timestamps
  - Correcting inconsistent log formats
  - Flagging sensor readings that fall outside realistic ranges
- Data cleansing benefits include:
  - Preventing models from learning incorrect patterns
  - Provides indirect security benefits such as identifying SQLi payloads before that data is used to train the model
- Poor cleansing can enable data poisoning, where malicious or malformed records skew the trained model.
