# Data balancing

- AI models depend on balanced training data to make fair and accurate decisions
- In real-world data sets, some classes of data are far more common than others which creates a class imbalance.
- Data balancing techniques address this issue by adjusting how the training data is distributed.
- Techniques include:
  - Oversampling:
    - Increase the number of minority-class examples.
    - Duplicate or synthetically create new records.
  - Undersampling:
    - Reduce the number of majority-class samples
    - Make the dataset more even
  - SMOTE:
    - Synthetic Minority Oversampling Technique
    - Create realistic new samples of the underrepresented class without duplication
- Security relevance: imbalanced data can cause models to miss rare events such as intrusions or fraud (high false-negative rate).
