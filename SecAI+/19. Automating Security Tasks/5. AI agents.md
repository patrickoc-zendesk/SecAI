# AI agents

- AI systems which operate with some degree of autonomy
- Contains 3 components:
  - Perception
  - Reasoning
  - Action
- AI agents do not just follow a fixed set of instructions; they can act, adapt and plan independently
- Can use tools, call APIs and chain steps to achieve a goal
- Security use cases: automated triage, threat hunting, orchestrating responses
- Risks: unpredictable behaviour, excessive autonomy, prompt injection and misuse of connected tools; scope permissions tightly and monitor actions
