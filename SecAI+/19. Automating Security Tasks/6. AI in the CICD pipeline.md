# AI in the CI/CD pipeline

- AI can be embedded into the `CI/CD` pipeline to support code scanning, dependency analysis and quality testing
- Code scanning:
  - Analyse source code for issues, bugs and poor practices
  - Traditional tools are static and return a high false-positive rate
  - AI interprets what the code is doing and determines if it is a risk
  - AI can also incorporate feedback to improve suggestions
- SCA (Software Composition Analysis):
  - Identify external components in code
  - AI assists in SCA by interpreting the results
  - Assess the library usage
  - Determine exposure
  - Suggest upgrade paths
  - Monitor threat intelligence
- Unit testing:
  - Evaluate a small segment of code
  - Requires a clear understanding of the code
  - AI can help create test cases
  - Suggest inputs
  - Identify gaps
- Regression testing:
  - Evaluates changes in code
  - Select relevant tests
  - Identify redundant tests
  - Suggest additional tests
  - Detect failures
- Model testing:
  - Evaluates AI performance
  - Generate test inputs
  - Check for bias
  - Identify edge cases
  - Monitor for performance drift
- Automated deployment:
  - AI can help gate releases, review deployment configs and detect anomalies before rollout
