# Model denial of service

- Focuses on disrupting the ability of the AI model to properly answer user requests
- Model DoS attacks consume resources needed by other users
  - Complex prompts that spike memory use, trigger long and expensive computation paths, or exploit weaknesses in how the model handles certain tokens
  - Recursive instructions
  - Complex Unicode characters
- Can also inflate cost in metered/pay-per-token services (sometimes called denial of wallet)
- Maps to OWASP Top 10 for LLM Applications (Model Denial of Service / Unbounded Consumption)
- Mitigations:
  - Strong resource isolation between users
  - Rate limiting and quotas per user or API key
  - Cap input length and output tokens
  - Monitor resource usage for anomalies
