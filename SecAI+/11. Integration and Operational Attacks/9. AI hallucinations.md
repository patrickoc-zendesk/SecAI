# AI hallucinations

- Occurs when AI fabricates results that are false but presented confidently
- These emerge from the model, typically as a result of how it generalises language patterns during training
- The model predicts plausible-sounding text rather than retrieving verified facts
- Example: inventing citations, case law, APIs or package names that do not exist
- Fabricated package names can enable slopsquatting (registering the hallucinated package with malicious code)
- Hallucinations can be dangerous in sensitive settings
- Mitigations:
  - Ground responses with retrieval (RAG) and cite sources
  - Human review of output before it is relied upon
  - Verify factual claims against trusted sources
