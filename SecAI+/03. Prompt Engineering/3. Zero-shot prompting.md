# Zero-shot prompting

- Zero-shot prompting only includes the instruction for a model and relies entirely on what it already knows.
- Responses are based on pre-trained knowledge.
- Performance depends largely on how clearly the task is described.
- Is best used for simple tasks or tasks the model is trained for.
- Improvements can be made by specifying the desired output or focus area.
- No examples are provided in the prompt, unlike one-shot or multi-shot prompting.
