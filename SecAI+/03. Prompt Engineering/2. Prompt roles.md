# Prompt roles

- Structured roles are used to organise interactions.
- This helps maintain consistency throughout an interaction.
- There are three main roles in most frameworks:
  - System prompt
    - Defines how the AI model should behave, such as the tone and boundaries it should follow.
  - User prompt
    - Describes what the AI model should do; the question from the user interacting with the model.
  - Assistant prompt
    - Sometimes provided to the AI as a template/example of the expected tone, structure and reasoning behind the answers it should provide.
- Security relevance: the system prompt sets guardrails, so attackers target it with prompt injection to override boundaries; user-supplied content should never be trusted as instructions.
