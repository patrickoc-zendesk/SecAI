# One-shot prompting

- Includes a single example with the instruction.
- The example helps provide the tone and style of the output.
- This is useful when a simple instruction is not enough.
- It shows the AI exactly how the task should be handled.
- Sits between zero-shot (no examples) and multi-shot (several examples).
