# Prompt engineering

- A prompt is the instruction given to a Generative AI model to produce a response.
- Prompt engineering is the process of crafting prompts that yield the best response.
- Precision of the prompt will create a better output from the model.
- A well-formed prompt typically supplies context, a clear task and any constraints on the output format.
- Security relevance: poorly constrained prompts widen the attack surface for prompt injection and jailbreaks; clear boundaries and input validation reduce this risk.
