# Multi-shot prompting

- Includes several examples with the instruction.
- By reviewing several examples, the model will better create an output which requires structured reasoning such as log analysis, alert triage or policy creation.
- This can create results almost as accurately as what could be achieved with fine-tuning, without the additional computational cost.
- Also known as few-shot prompting.
