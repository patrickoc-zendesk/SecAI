# Model deployment and integration

- Model deployment considerations include:
  - Hardening deployment infrastructure
  - Enforce access control
  - Protect the model asset
  - Validate inputs and outputs (secure integration)
  - Enable secure logging
- Input validation and output filtering help defend against prompt injection and adversarial inputs.
- Protecting the model asset guards against model theft and unauthorised extraction of weights.
