# Model development and selection

- This stage begins with choosing the algorithm or architecture that will best meet the project objectives.
- The selected model is trained on the prepared data to learn patterns and guide decision making.
- Training environments must be tightly controlled using:
  - Firewalls
  - Encryption
  - Strong access control
- Choosing the right model impacts how vulnerable the feature will be:
  - Simple decision tree / linear regression models are less vulnerable.
  - Neural networks are more powerful but also more prone to being manipulated.
- If a pre-trained model is chosen, hidden backdoors or malicious code can be introduced through unverified providers.
- Mitigate supply-chain risk by sourcing models from trusted registries and verifying integrity (e.g., checksums, signed artefacts).
