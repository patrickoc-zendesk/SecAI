# Model evaluation and validation

- Evaluation measures how accurately a model performs.
- Validation confirms that it behaves ethically, securely and within the organisation's expectations.
- Evaluation:
  - The model is tested on unseen data.
  - This helps determine generalisation.
  - Accuracy, precision, recall and `F1` scores are measured to gauge performance.
  - A model performing well on training data but struggling with unseen data is likely overfit.
- Validation:
  - Assess whether the model meets fairness, security and compliance standards.
  - Can also include red team exercises.
- Overfitting can be reduced with techniques such as cross-validation, regularisation, and holding out a separate test set.
