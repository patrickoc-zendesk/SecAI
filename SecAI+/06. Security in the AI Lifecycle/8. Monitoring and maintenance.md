# Monitoring and maintenance

- Benefits of monitoring:
  - Helps detect data drift and model drift.
    - Data drift:
      - Data entering the model changes from what it was trained on (e.g., a change in customer buying habits).
    - Model drift:
      - A model's internal parameters or assumptions degrade.
      - This can occur as the environment or the behaviour it is predicting begins to evolve.
  - Helps detect unexpected behaviour or potential attacks.
- Security patching and library updates are critical.
- Model maintenance includes:
  - Retraining:
    - Rebuilding the model with new, verified data to correct drift or address emerging risks.
  - Tuning:
    - Making small adjustments such as refining thresholds or hyperparameters to optimise performance without requiring a rebuild.
