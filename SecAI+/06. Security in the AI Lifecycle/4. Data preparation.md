# Data preparation

- Also known as preprocessing.
- Data preparation involves cleaning, organising and securing raw data so it can be used effectively in model development.
- This stage further builds on ensuring that data is of high quality and that it is safe for modelling.
- Data preparation should happen in a secure and controlled environment:
  - Trusted tools
  - Secure pipelines
- Data preparation goes through the following steps:

1. Problem framing and data profiling
2. Data cleansing
   - Deduping
   - Fix errors
   - Handle missing data
   - Eliminate outliers that could distort results
3. Data sanitisation (required for standards such as HIPAA/GDPR)
   - Masking
   - Tokenisation
   - Anonymising PII
4. Data validation and verification (compare against authoritative sources)
   - Check if values are accurate
   - Complete
   - Properly formatted
5. Data splitting
   - Divide data into training, validation, and test sets
6. Data augmentation
   - Create additional training examples to improve coverage
   - Create synthetic examples, or transform data to improve model robustness and balance

- Version control and lineage tracking are also important in data processing:
  - Record how data sets evolve through successive cleaning and transformation steps.
- Maintaining traceability is critical for debugging, audits, and demonstrating compliance with internal and external data standards.
- Quality assurance should always remain a top priority during data preparation.
