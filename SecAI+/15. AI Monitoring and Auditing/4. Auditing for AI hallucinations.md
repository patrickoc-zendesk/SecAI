# Auditing for AI hallucinations

- A process that ensures AI systems generate accurate, trustworthy and verifiable information
- Measures whether the system meets the established standards for reliability, compliance and security
- Hallucinations occur when a model generates false information and presents it as true
- Auditors detect and compute hallucination rates by comparing sample outputs to trusted sources
- Hallucinations can be reduced by:
  - Requiring citations for important claims
  - `RAG` (Retrieval-Augmented Generation) to ground responses in verified source data
  - Leveraging automated detection tools
  - Human verification
