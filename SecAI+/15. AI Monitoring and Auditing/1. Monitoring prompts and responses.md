# Monitoring prompts and responses

- Involves capturing and reviewing both the inputs that users send to the model and the outputs it generates
- Helps detect unusual activity, prevent abuse, and maintain visibility into how people interact with the system
- Attacks such as prompt injection can be identified through monitoring
- Monitoring the response should be done for accuracy, safety and compliance
- Response monitoring also includes tracking model confidence levels, which indicate how certain the model is about its answers
  - Used to identify drift or loss of accuracy
  - If confidence is high but accuracy is low then the model should be recalibrated
- Feeding prompt and response telemetry into a `SIEM` can reveal larger attack patterns that may otherwise go unnoticed
- Capture logs must themselves be protected, as prompts and responses can contain sensitive or personal data
