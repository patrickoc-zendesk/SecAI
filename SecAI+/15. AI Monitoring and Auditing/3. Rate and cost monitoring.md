# Rate and cost monitoring

- Rate monitoring tracks how often key events occur in an AI system over time
  - Detects security incidents
  - Identifies bugs
  - Maintains fairness in shared environments
    - Identify areas for throttling and rate limiting
  - Enables adaptive rate limiting
- Cost monitoring safeguards financial resources by tracking usage and related costs
  - Prompt and response costs (AI models bill on input and output tokens)
  - Compute and storage costs
    - Memory, disk space, input/output performance
  - Third-party API costs
  - Budget alerts and spending limits support cost monitoring and control
- Sudden spikes in rate or cost can signal abuse such as denial-of-wallet attacks, where an attacker drives up token or API spend to exhaust budgets
