# Obfuscation

- GenAI allows automated ways to mutate code, rewrite macros, and cloak data so that security tools struggle to recognise a threat signature or pattern
- Polymorphic malware is another capability, which changes on each system it infects, making signature identification difficult
- Undermines signature-based detection, pushing defenders toward behaviour- and anomaly-based approaches
- Mitigations: behavioural detection, endpoint detection and response (`EDR`), and sandboxing to observe runtime behaviour rather than static signatures
