# Reconnaissance

- LLMs are very effective at performing recon by ingesting raw data to identify vulnerable infrastructure and weaknesses
- Automates open-source intelligence (`OSINT`) gathering across public records, social media, and leaked data at scale
- Nation-state-backed groups frequently use LLM-enhanced recon
- Identifiers include:
  - Spikes in automated profile views
  - Bulk API queries that reflect machine-generated patterns
- Mitigations: rate limiting, bot detection, and minimising publicly exposed sensitive information
