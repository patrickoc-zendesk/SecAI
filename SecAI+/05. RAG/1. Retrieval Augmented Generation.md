# Retrieval Augmented Generation

- RAG is a technique to improve accuracy and reliability of an AI system by combining generative modelling with external knowledge retrieval.
- RAG allows a model to look up current and relevant data at runtime.
- RAG works by:
  - Converting a user query into an embedding; a numerical representation of the input.
  - The system searches a database called a vector store which holds embeddings of documents or knowledge sources.
  - The most similar pieces of information are retrieved and provided to the model as context before it generates an answer.
- RAG improves accuracy, transparency, explainability and content control.
- It reduces hallucinations by grounding responses in retrieved source data.
- Security relevance: the knowledge store, retrieval channel and retrieved content each need protection against poisoning, tampering and data leakage.
