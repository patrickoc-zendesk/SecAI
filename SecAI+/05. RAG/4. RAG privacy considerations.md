# RAG privacy considerations

- RAG can risk exposing sensitive data when pulling from live databases if privacy safeguards are not in place.
- By using RAG, the model does not need to store private information in its own weights.
- Privacy considerations:
  - Avoid cross-session reuse of data.
    - Prompt engineering techniques and session-based controls can help keep retrieved data isolated from other interactions.
  - Encryption and access control.
  - Confidential data should not be quoted directly in responses.
  - Apply data minimisation so only the data needed for the task is retrieved.
