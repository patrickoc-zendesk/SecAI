# Securing the knowledge store

- The knowledge store often takes the form of a vector database which holds embeddings of inputs.
- Embeddings can still be reconstructed, or the original content can be inferred from them (embedding inversion).
- Securing the knowledge store includes:
  - Enforcing strict access controls and encrypting the data at rest and in transit.
  - Enabling logging and monitoring.
  - Applying least privilege so only authorised services and users can query or modify the store.
