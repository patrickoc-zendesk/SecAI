# IDE plug-ins

- Integrate AI assistance directly into the developer's code editor (e.g. VS Code, JetBrains)
- Used to improve code quality, identify risky patterns, and detect secrets and insecure libraries
- Can suggest fixes and secure alternatives inline as code is written (shift-left security)
- Security caution: plug-ins may transmit source code to external services, and AI-suggested code can itself introduce vulnerabilities if accepted unreviewed
