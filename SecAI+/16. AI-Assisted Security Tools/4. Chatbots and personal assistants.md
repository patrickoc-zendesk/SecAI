# Chatbots and personal assistants

- Chatbots provide front-end support on common security tools
- AI personal assistants enhance office productivity (e.g. drafting, scheduling, summarising)
- Can lower the barrier to querying security data using natural language
- Security caution: sensitive or confidential data entered into public chatbots may be retained or used for training, creating data leakage risk
