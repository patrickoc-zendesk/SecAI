# Browser plug-ins

- AI-powered browser extensions provide enhanced capabilities
  - URL analysis
  - Malicious IP scanning
- Review security reports
- Can be used to identify security risks on a webpage
- Security caution: extensions run with broad access to browsing data, so they expand the attack surface and can leak sensitive page content to third parties
