# MCP servers

- Model Context Protocol (`MCP`) allows AI applications to interact with external tools and data sources through a standardised interface
- `MCP` use can support least privilege
  - Offers a small set of approved actions for the AI tool to use, and can block unwanted actions
- `MCP` enables governance and compliance
- Security caution: `MCP` servers expand the attack surface; a compromised or malicious server can expose tools or data to the model, so servers should be trusted, scoped, and monitored
