# Model guardrails

- Technical and policy safeguards that keep an AI system operating safely.
- Ensures that the model behaves within acceptable limits, avoids harmful outputs, and follows security and ethical guidelines.
- Protects users, data, and organisations from unintended or unsafe behaviour by AI systems.
- Guardrail techniques include:
  - Rule-based filtering
    - Block forbidden topics / PII
  - Content moderation
    - Uses a secondary model to assess if input data is safe
    - Detects hate speech, self-harm, explicit material
    - Tuning is required
  - Response tuning and refusal
    - The model is trained to disallow specific prompts
  - Constrained output formatting
    - Prevents errors and ensures compatibility with downstream systems.
    - Reduces the risk of the model injecting unintended or unsafe content into structured outputs.
- Model guardrails can be difficult to balance:
  - Can be overly strict
  - Block legitimate use cases
  - Poorly tuned moderation systems can overreact or fail to catch violations.
