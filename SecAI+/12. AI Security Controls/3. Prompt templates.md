# Prompt templates

- Act like reusable scripts that tell the model what role to take, the tone to use, and what limits to follow.
- They wrap the input into a structured format to ensure the AI stays on task and produces consistent and safe responses.
- A standardised prompt which contains predefined instructions with one or more open slots for user input.
- Helps to standardise interactions across teams and users.
- Can also serve as a security control to defend against prompt injection attacks.
  - A user could try inserting hidden instructions into their prompt to override system rules. With prompt templating, however, the model can be constrained to only process user input that fits within a specific slot.
  - When combined with output filters such as content moderation, templates form a strong first line of defence.
