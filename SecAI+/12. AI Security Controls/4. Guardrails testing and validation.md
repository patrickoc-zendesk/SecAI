# Guardrails testing and validation

- Essential for keeping AI systems safe, reliable, and compliant.
- Validation and testing are required to ensure guardrails remain effective against constantly evolving attack techniques unique to AI systems.
  - Including prompt injection, obfuscated inputs, and filter bypass techniques using prompts.
- Regular testing and validation confirms guardrails still perform as intended and that any updates or retraining performed do not introduce new vulnerabilities.
- Guardrail testing and validation techniques include:
  - Jailbreak testing
  - Output validation
    - Use canary string identification
  - Log monitoring
  - Human feedback
