# LLMs vs SLMs

|                       | LLM                                                            | SLM                                                                        |
| --------------------- | -------------------------------------------------------------- | -------------------------------------------------------------------------- |
| Model size            | 100s of billions of parameters                                 | Millions to a few billions                                                 |
| Training data         | Enormous general datasets which can span the entire internet   | Fine-tuned on smaller, domain-specific datasets                            |
| Capabilities          | Versatile with no need for prior examples                      | Specialised on niche tasks. Requires fine-tuning.                          |
| Resource requirements | Substantial computing power (run in large cloud environments). | Lightweight and can be run on-prem or on edge devices or standard servers. |
| Pros                  | Versatile, powerful, externally maintained                     | Quick, efficient, cost effective, privacy                                  |
| Cons                  | Price, latency, environmental, cloud overhead                  | Not as powerful, requires a balance of power and performance               |

- A balance between performance, cost, compliance and security is required to determine which is the best solution for a company.
- Running an SLM on-prem keeps sensitive data in-house, reducing exposure compared with sending prompts to an external cloud LLM.
