# Natural language processing

- Enables machines to process and generate human language.
- Early NLP relied on statistical models such as Bayesian classifiers, which can identify basic patterns but miss nuanced and context dependent data.
- Modern NLP uses deep learning to attempt to capture meaning and relationships between words (i.e. intent).
- Security uses include spam and phishing detection, log analysis and parsing threat intelligence reports.
