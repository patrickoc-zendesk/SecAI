# Generative AI

- Produces new content from existing data.
- GenAI can be used to help defenders by:
  - Creating synthetic data if it is sparse or too sensitive (artificial malware or simulated network traffic).
- Can be used by attackers to:
  - Send polymorphic malware (malicious scripts rewritten by AI) so that it looks different each time, deep fakes, synthetic voices and convincing phishing campaigns.
- GAN (Generative Adversarial Network) is an example of an architecture used to train GenAI.
  - Two models are used against each other in order to train the whole (a generator creates data while a discriminator attempts to identify what data is generated by AI).
- Transformers are another example of GenAI architecture which is used in code generation, NLP and text summarisation.
  - Used behind most LLMs.
