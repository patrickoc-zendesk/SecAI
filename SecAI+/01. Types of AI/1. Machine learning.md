# Machine learning

- A sub-field within AI focused on developing algorithms that improve and learn over time.
- ML models find patterns in large datasets and use those patterns to make predictions or classifications.
- In cybersecurity, ML based systems can be used to detect anomalous network activity.
- ML models can quickly adapt to new threats as they constantly learn from new data.
- A key concept used by ML is statistical learning.
  - Use statistics and probability to understand data (prediction + interpretation).
- Logistic regression is an example of statistical learning.
  - Predicts a probability that an input belongs to a class (binary outcome).
  - Can be used to identify spam emails.
- Clustering is another example of statistical learning.
  - Groups similar data points together without predefined labels.
  - Can be used to monitor network traffic; anomalous activity is identified as an outlier.
