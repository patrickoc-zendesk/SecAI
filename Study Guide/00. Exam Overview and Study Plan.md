## What is CompTIA SecAI+?

CompTIA SecAI+ (exam code **CY0-001 V1**, launched 17 Feb 2026) is CompTIA's certification for **securing, governing, and responsibly integrating AI into cybersecurity operations**. It targets practitioners who already work in security — you are securing AI systems, using AI to assist security work, and governing it.

## Exam facts

| Item | Detail |
| --- | --- |
| Exam code | CY0-001 V1 |
| Questions | Up to 60 (multiple-choice + performance-based) |
| Time | 60 minutes |
| Passing score | 600 (on a 100–900 scale) |
| Recommended experience | 3–4 years IT, ~2 years hands-on cybersecurity; Security+, CySA+, or PenTest+ recommended |
| Languages | English, Japanese |

> [!tip] How the exam tests
> Beta-exam feedback: the exam is **scenario-heavy** — it tests applied decision-making, not definition recall. Expect "given a scenario, choose the best control" questions throughout Domain 2, and GRC questions that make you **apply** frameworks (e.g., distinguish the EU AI Act's binding requirements from NIST AI RMF's voluntary recommendations).

## How to use this guide

1. **Work module by module** — each guide file consolidates your course notes for that module and expands them to exam depth, with an *Exam Focus* section and *Self-Check* questions.
2. **Master the distractor pairs** — the exam's "compare and contrast" questions live or die on these (see the pairs list in [[22. Cheat Sheet]]).
3. **Think in scenarios** — for every attack, know: what it is → how it works → what evidence it leaves → which compensating control is best. That four-part shape IS objective 2.6.
4. **Apply frameworks, don't recite them** — for GRC, always ask "binding law or voluntary framework?" before answering.

## Suggested study plan (3 weeks, ~1–1.5 h/day)

Weight the time by domain, not by module count:

| Days | Focus | Why |
| --- | --- | --- |
| 1–3 | Modules 01–07 (Domain 1) | Foundations — you know much of this; move fast, focus on distinctions you don't use daily (epoch/pruning/quantization, lineage vs provenance) |
| 4–9 | Modules 08–15 (Domain 2) | **40% of the exam** — attacks (08–11) then controls (12–15); this is where the PBQs live |
| 10–12 | Modules 16–19 (Domain 3) | Tools, use cases, AI-enabled attacks, automation |
| 13–14 | Module 20 (Domain 4) | GRC — smallest module guide, but scenario-heavy on the exam; drill the framework comparison table |
| 15–16 | [[22. Cheat Sheet]] + [[21. Glossary and Acronyms]] | Rapid review of every distractor pair, attack signature, and framework |
| 17–18 | [[23. Practice Questions]] | Full-length timed run (60 min), then review every wrong answer back to its module |
| 19–21 | Weak-area review | Re-read the *Exam Focus* + *Self-Check* sections of your 5 weakest modules |

## Exam-day tactics

- ~60 minutes for ~60 questions ≈ **one minute per question**. Don't stall; flag and move.
- Do the multiple-choice questions first if the interface allows flagging, then return to performance-based items — bank the easy points first.
- For "best control" questions, eliminate the controls that don't address the *root cause* in the scenario before picking.
- Answer every question — no penalty for guessing.
